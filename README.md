# ⚙️ Installation

```bash
# Clone Repository
git clone https://github.com/jayprajapati27/jayprajapati-portfolio.git

# Open Folder
cd jayprajapati-portfolio

# Install Dependencies
npm install

# Run Development Server
npm run dev
```
